# Baofeng_UV-5RM-Pro-GPS
My attempt at dev-ing out the Baofeng UV-5RM Pro GPS (UV-5RM Plus GPS) CHIRP driver for ticket #11834.
[https://chirpmyradio.com/issues/11669](https://chirpmyradio.com/issues/11834)


Although the driver technically can write, it has not been tested. I DO NOT RECOMMEND WRITING to the device yet. This is still experimental and so far most of the effort has gone to reading and mapping out the memory functions.

Co-developed using Gemini AI.
